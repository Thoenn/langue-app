# 6. Verbes modaux & Auxiliaires

| Français | English | Contexte |
|----------|---------|----------|
| Je veux | I want | Désir |
| Je voudrais / J'aimerais | I would like | Souhait poli — "je voudrais" est plus direct que "j'aimerais" |
| Je peux | I can | Capacité |
| Je pourrais | I could | Conditionnel poli : "je pourrais pas" → "I couldn't" |
| Je dois | I must / I have to | Obligation |
| Il faut | It is necessary / One must | Impersonnel — très important en français |
| Il faut que + subjonctif | (one) must + verb | "il faut que je révise" = I have to study |
| On peut | We can / One can | Possibilité collective |
| Tu pourrais | You could (informal) | Demande polie : "tu pourrais m'expliquer" |
| Vous pouvez | You can (formal/plural) | Capacité poli/pluriel |
| Je vais + infinitif | I am going to + verb | Futur proche : "je vais faire" = I'm going to do |
| Je sais / Je ne sais pas | I know / I don't know | |
| J'ai / Je n'ai pas | I have / I don't have | |

**Commentaire :** "Il faut" n'a pas d'équivalent direct parfait en anglais. "I have to" / "one must" / "it's necessary" selon le contexte. "Je voudrais" est plus poli que "je veux".

# 26. Erreurs typiques de français

| Erreur (FR) | Correction (FR) | English equivalent | Commentaire |
|-------------|-----------------|-------------------|-------------|
| "c toi" | "c'est toi" | it's you | Il manque "est" |
| "c mes clé" | "ce sont mes clés" | they're my keys | Pluriel + "ce sont" |
| "j'ai pas vue" | "je n'ai pas vu" | I didn't see | "Vue" est le participe féminin — à corriger |
| "sa a était annulé" | "ça a été annulé" | it was canceled | "Sa" ≠ "ça" ; "était" ≠ "été" |
| "ducoup je suis rentrer" | "du coup je suis rentré(e)" | so I went home | "Rentrer" = infinitif → "rentré" = participe passé |
| "g pas le code" | "je n'ai pas le code" | I don't have the code | Abréviation texto |
| "il me répondront" | "ils me répondront" | they'll answer me | "Il" (singulier) ≠ "Ils" (pluriel) |
| "sa devrais le faire" | "ça devrait le faire" | that should do it | "Sa" + conditionnel mal accordé |
| "elle s'appeler" | "elle s'appelle" | her name is | Infinitif au lieu du présent |
| "enleve le message" | "enlève le message" | remove the message | Accent manquant |
| "sur plusieur chapitre" | "sur plusieurs chapitres" | on several chapters | Singulier au lieu du pluriel |
| "par rapprt au" | "par rapport au" | compared to / regarding | Abréviation incorrecte |
| "les credentials ne marchent pas" | "les identifiants ne marchent pas" | the credentials don't work | Anglicisme (acceptable mais "identifiants" recommandé) |
| "persiste les donnes" | "persiste les données" | persist the data | "Donnes" = verbe ; "données" = nom |
| "lancer plusiurs instance" | "lancer plusieurs instances" | launch multiple instances | Orthographe |

**Commentaire :** Ces erreurs sont typiques du français texto/rapide. Pour apprendre l'anglais, ces fautes n'ont pas d'équivalent direct, mais l'important est de repérer les patterns : Michel écrit parfois comme il parle (phonétique). En anglais, attention aux erreurs similaires (your/you're, its/it's, there/their/they're).
